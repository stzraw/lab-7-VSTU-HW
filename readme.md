# Домашнее задание к работе 7

## Условие задачи
Составить программу, которая для каждой введенной цифры (0-9) вывести
соответствующее ей название на английском языке (0 – zero, 1 – one, 2 – two ...).

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**.
2. Инициализация окружения: установка локализации UTF-8 для корректного вывода символов.
3. Ввод исходных данных с клавиатуры:
   - Ввести целое число n (цифру от 0 до 9)
4. Вызов функции: передать значение n в функцию slovo и сохранить ответ в переменную res.
5. Многоальтернативный выбор (switch по значению res) и вывод результата:
   - При res == 0: вывести «0 - zero»
   - При res == 1: вывести «1 - one»
   - При res == 2: вывести «2 - two»
   - При res == 3: вывести «3 - three»
   - При res == 4: вывести «4 - four»
   - При res == 5: вывести «5 - five»
   - При res == 6: вывести «6 - six»
   - При res == 7: вывести «7 - seven»
   - При res == 8: вывести «8 - eight»
   - При res == 9: вывести «9 - nine»
   - Иначе (default): вывести сообщение об ошибке «Ошибка: введена не цифра от 0 до 9»
6. **Конец**.

**Часть 2: Расчетная функция (slovo)**
1. **Начало функции**: получение параметра n.
2. Проверка принадлежности числа диапазону цифр от 0 до 9:
   - Если n >= 0 и n <= 9, вернуть значение n обратно в вызывающую функцию (main).
   - Иначе вернуть значение -1 (код ошибки) обратно в вызывающую функцию (main).
3. **Конец**.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

int slovo(int n);

int main()
{
    int n, res;

    setlocale(LC_ALL, ".UTF8");

    printf("Введите цифру (0-9): ");
    scanf("%d", &n);

    res = slovo(n);

    switch (res)
    {
        case 0:
            printf("0 - zero\n");
            break;
        case 1:
            printf("1 - one\n");
            break;
        case 2:
            printf("2 - two\n");
            break;
        case 3:
            printf("3 - three\n");
            break;
        case 4:
            printf("4 - four\n");
            break;
        case 5:
            printf("5 - five\n");
            break;
        case 6:
            printf("6 - six\n");
            break;
        case 7:
            printf("7 - seven\n");
            break;
        case 8:
            printf("8 - eight\n");
            break;
        case 9:
            printf("9 - nine\n");
            break;
        default:
            printf("Ошибка: введена не цифра от 0 до 9\n");
            break;
    }
    return 0;
}

int slovo(int n)
{
    if (n >= 0 && n <= 9)
    {
        return n;
    }
    else
    {
        return -1;
    }
}
```
